# Roadmap

Small, focused improvements are preferred over adding content feeds or background services. These are areas for contribution, not scheduled commitments.

- Collect compatibility reports across TV brands, Google TV, and Android versions.
- Test reboot, standby/wake, and physical-remote long-press behavior.
- Add virtual accessibility nodes and improve screen-reader focus.
- Move interface text into resources and add reviewed translations.
- Improve OEM app-label handling and custom favourite selection on first launch.
- Consider optional local wallpaper selection with a narrow Android document-picker flow.
- Separate view, app discovery and preference state as the project grows.

Ads, required accounts, analytics and a recommendation feed are outside the project's current direction.
