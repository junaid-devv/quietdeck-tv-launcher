# Roadmap

## Implemented in the 2.0 candidate

- Native accessible widgets and visible app options.
- Proportional artwork, lazy loading, bounded memory caching and recycled tiles.
- Search, user-selected favourites, recent apps and named collections.
- Grid density, label size, high contrast, original scenes and local wallpaper.
- Validated local configuration backup/restore and in-app privacy policy.
- Optimized release APK/AAB, emulator tests and repeatable startup/memory evidence.
- Original logo and Play listing asset package.

## Required before production

- Physical low-RAM TV, certified Google TV and another manufacturer: remote, accessibility, firmware Home restrictions, upgrade, reboot, standby/wake and recovery.
- Genuine final-version TV screenshots and verified Play-delivered update signing.
- Account setup, public support email, declarations, internal distribution and mandatory personal-account closed testing.
- Performance baselines on the same physical hardware, with startup, focus latency, frame and memory regression gates set from measurements.

See [release readiness](RELEASE-READINESS.md) and [Play handoff](../play/PUBLISHING.md). Future localization must ship matching app and listing translations. Product expansion should preserve local operation and a quiet Home screen.
