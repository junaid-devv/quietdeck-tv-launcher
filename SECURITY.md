# Security policy

## Scope

QuietDeck TV is an early-stage local launcher. The current public release is the focus of fixes; there is no promised long-term support schedule. The APK requests no permissions and contains no network client, but code and installation instructions can still contain defects.

## Report privately

Use the repository's [private vulnerability reporting](https://github.com/junaid-devv/quietdeck-tv-launcher/security/advisories/new) when available. Include the affected version, Android version, reproduction steps, impact and relevant sanitized logs. Avoid public disclosure of signing keys, account information or pairing codes.

For ordinary bugs without a security impact, use the issue templates. There is no guaranteed response time or bug bounty.

## Releases

Download official APKs from this repository's Releases page. Compare the published checksums and signing-certificate fingerprint. Never publish a private signing key or use a development CI artifact as if it were an official release.
