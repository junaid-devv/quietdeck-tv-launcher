# Community guidelines

QuietDeck TV welcomes useful feedback and contributions from people with different backgrounds and levels of experience.

- Be respectful, specific and constructive.
- Discuss behavior and evidence rather than attacking people.
- Do not post harassment, threats, discrimination, spam or someone else's private information.
- Remove personal information from device logs and screenshots before sharing them.
- Accept that maintainers may close off-topic requests or remove harmful content.

These guidelines apply to this project's issues, pull requests and other project spaces. Use GitHub's reporting tools for abusive content. Security vulnerabilities belong in [private vulnerability reporting](SECURITY.md), not public discussion.
